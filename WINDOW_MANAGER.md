# Window Manager Hotkeys
Hotkeys should be the same regardless if it's a Mac specific keyboard or not.

## Focus Windows
- `Alt (Left)` + `H`: Focus the window to the **west**
- `Alt (Left)` + `J`: Focus the window to the **south**
- `Alt (Left)` + `K`: Focus the window to the **north**
- `Alt (Left)` + `L`: Focus the window to the **east**

## Move Windows
- `Shift (Left)` + `Alt (Left)` + `H`: Swap the window to the **west**
- `Shift (Left)` + `Alt (Left)` + `J`: Swap the window to the **south**
- `Shift (Left)` + `Alt (Left)` + `K`: Swap the window to the **north**
- `Shift (Left)` + `Alt (Left)` + `L`: Swap the window to the **east**

## Focus Workspace
- `Alt (Left)` + `1`: Focus workspace 1
- `Alt (Left)` + `2`: Focus workspace 2
- `Alt (Left)` + `3`: Focus workspace 3
- `Alt (Left)` + `4`: Focus workspace 4
- `Alt (Left)` + `5`: Focus workspace 5
- `Alt (Left)` + `6`: Focus workspace 6
- `Alt (Left)` + `7`: Focus workspace 7
- `Alt (Left)` + `8`: Focus workspace 8
- `Alt (Left)` + `9`: Focus workspace 9
- `Alt (Left)` + `0`: Focus workspace 10

## Move Workspace
- `Shift (Left)` + `Alt (Left)` + `1`: Move window to workspace 1 and focus it
- `Shift (Left)` + `Alt (Left)` + `2`: Move window to workspace 2 and focus it
- `Shift (Left)` + `Alt (Left)` + `3`: Move window to workspace 3 and focus it
- `Shift (Left)` + `Alt (Left)` + `4`: Move window to workspace 4 and focus it
- `Shift (Left)` + `Alt (Left)` + `5`: Move window to workspace 5 and focus it
- `Shift (Left)` + `Alt (Left)` + `6`: Move window to workspace 6 and focus it
- `Shift (Left)` + `Alt (Left)` + `7`: Move window to workspace 7 and focus it
- `Shift (Left)` + `Alt (Left)` + `8`: Move window to workspace 8 and focus it
- `Shift (Left)` + `Alt (Left)` + `9`: Move window to workspace 9 and focus it
- `Shift (Left)` + `Alt (Left)` + `0`: Move window to workspace 10 and focus it

## Open Applications
- `Windows` + `1`: Open **Browser** in workspace 1
- `Windows` + `2`: Open **Development** in workspace 2
- `Windows` + `3`: Open **API** in workspace 3
- `Windows` + `4`: Open **Figma** in workspace 4
- `Windows` + `5`: Open **Notes** in workspace 5
- `Windows` + `6`: Open **Stream** in workspace 6
- `Windows` + `7`: Open **Chat** in workspace 7
- `Windows` + `8`: Open **Files** in workspace 8
- `Windows` + `9`: Open **Music** in workspace 9
- `Windows` + `0`: Open **Message** in workspace 0

## Resize Windows
- `Alt (Left)` + `U`: Resize window **left**
- `Alt (Left)` + `P`: Resize window **right**
- `Alt (Left)` + `I`: Resize window **bottom**
- `Alt (Left)` + `O`: Resize window **top**

## Layout Orientation
- `Alt (Left)` + `-`: Insert window or Change orientation to **east**
- `Alt (Left)` + `\`: Insert window or Change orientation to **south**

## Window Controls
- `Alt (Left)` + `Space`: Enable **float**
- `Shift (Left)` + `Alt (Left)` + `Space`: Disable **float**
- `Shift (Left)` + `Alt (Left)` + `Q`: Close window

## Reload Config
- `Shift (Left)` + `Alt (Left)` + `R`: Reload Config

## Cycle Wallpaper (Exclusive to Sway)
- `Windows` + `j`: Next Wallpaper
- `Windows` + `k`: Previous Wallpaper
