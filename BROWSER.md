# Browser Hotkeys
Hotkeys should be the same regardless if it's a Mac specific keyboard or not.

## Tab
- `Ctrl` + `T`: New Tab
- `Ctrl` + `Shift` + `T`: Reopen Closed Tab
- `Ctrl` + `W`: Close Tab
- `Ctrl` + `H`: Back
- `Ctrl` + `J`: Next Tab
- `Ctrl` + `K`: Previous Tab
- `Ctrl` + `L`: Forward
- `Ctrl` + `\`: Toggle vertical tabs expanded

## Page
- `Ctrl` + `R`: Reload
- `Ctrl` + `Shift` + `R`: Reload bypassing cache
- `Ctrl` + `P`: Focus Location

## Miscellaneous
- `Ctrl` + `B`: Copy URL
