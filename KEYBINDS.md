# Keybinds Hotkeys
Hotkeys should be the same regardless if it's a Mac specific keyboard or not.

## Rebinding
- `Caps Lock` to `Control (Left)`
- `Control (Left)` to `` ` ``

## MacOS Style Copy/Paste/Cut/Select
- `Alt (Left)` + `A`: Select
- `Alt (Left)` + `C`: Copy
- `Alt (Left)` + `V`: Paste
- `Alt (Left)` + `X`: Cut

## Vim Style Movement
- `Alt (Right)` + `H`: Left
- `Alt (Right)` + `J`: Down
- `Alt (Right)` + `K`: Up
- `Alt (Right)` + `L`: Right

## Vim Style Escape
- `Control (Left)` + `[`: Escape
