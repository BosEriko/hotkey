# Shell Hotkeys
In Tmux, the `Prefix` key is set to `C-g`, allowing you to trigger tmux commands without conflicting with your system-wide key mappings.

## General (Shell)
- `Control` + `E`: Open Explorer
- `Control` + `R`: Search History
- `Control` + `T`: Search Files

## General (Tmux)
- `Prefix` - `R`: Reload Tmux

## Window (Tmux)
- `Prefix` - `C`: New Window
- `Prefix` - `X`: Close Window
- `Prefix` - `,`: Rename Window
- `Prefix` - `\`: Split Window Vertically
- `Prefix` - `-`: Split Window Horizontally
- `Prefix` - `Control` + `H`: Go to Previous Window
- `Prefix` - `Control` + `L`: Go to Next Window

## Pane (Tmux)
- `Prefix` - `H`: Move to left pane
- `Prefix` - `J`: Move to bottom pane
- `Prefix` - `K`: Move to top pane
- `Prefix` - `L`: Move to right pane
- `Prefix` - `Shift` + `H`: Resize pane to the left
- `Prefix` - `Shift` + `J`: Resize pane to the bottom
- `Prefix` - `Shift` + `K`: Resize pane to the top
- `Prefix` - `Shift` + `L`: Resize pane to the right

## Modes (Tmux)
- `Prefix` - `Escape`: VIM Mode
- `Prefix` - `O`: OpenCode mode
